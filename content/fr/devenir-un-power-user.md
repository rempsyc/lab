Un **power user** connaît assez bien ses outils pour s’en servir plus efficacement. Ça peut vouloir dire adapter les réglages d’une application à sa façon de travailler, découvrir une fonction qui évite plusieurs étapes ou automatiser une tâche qu’on fait souvent.

**Les raccourcis clavier sont un bon point de départ.** Quand on peut changer de fenêtre, retrouver un passage dans un article ou modifier une phrase sans prendre la souris ni ouvrir un menu, il est plus facile de garder le fil. Choisissez deux raccourcis du Tier 1 à essayer dans votre travail cette semaine. **Maj** désigne la touche **Shift**.

## Tier 1 · Les raccourcis du quotidien

| Raccourci | Action |
| --- | --- |
| **Ctrl + F** | Trouver un mot ou une expression sur une page Web, dans un PDF ou dans un document. |
| **Alt + Tab** | Passer d’une application ou d’une fenêtre Windows à l’autre, par exemple entre un article et vos notes. |
| **Ctrl + Tab** / **Ctrl + Maj + Tab** | Passer à l’onglet suivant ou précédent dans le navigateur. |
| **Ctrl + T** / **Ctrl + W** | Ouvrir un nouvel onglet ou fermer l’onglet actif. |
| **Ctrl + Maj + T** | Rouvrir le dernier onglet fermé. Répétez le raccourci pour retrouver les précédents. |
| **F2** | Renommer le fichier ou le dossier sélectionné dans l’Explorateur de fichiers Windows. |
| **Alt + D** / **Ctrl + L** | Utilisez **Alt + D** d’une seule main pour aller à la barre d’adresse du navigateur. Si Google Docs intercepte le raccourci, essayez **Ctrl + L**. |

## Tier 2 · Les outils Windows

| Raccourci | Action |
| --- | --- |
| **Win + Maj + S** | Capturer une partie de l’écran. Sélectionnez la zone, puis collez l’image avec **Ctrl + V** ou ouvrez-la dans l’Outil Capture d’écran pour l’annoter. |
| **Win + Maj + T** | Ouvrir l’extracteur de texte intégré à Windows 11, puis sélectionner une zone pour copier le texte d’une image ou d’une page numérisée. Si le raccourci est indisponible dans votre version, faites une capture et choisissez **Actions de texte**. |
| **Win + H** | Dicter du texte. Placez le curseur dans un champ de texte, puis lancez la saisie vocale. |
| **Win + .** | Ouvrir le panneau d’émojis. Tapez un mot pour trouver un émoji. |
| **Win + S** | Ouvrir la recherche Windows pour trouver une application ou un fichier. |

## Tier 3 · Naviguer dans un texte et le modifier

| Raccourci | Action |
| --- | --- |
| **Ctrl + C** / **Ctrl + V** | Copier la sélection, puis la coller. |
| **Ctrl + Maj + V** | Coller du texte sans sa mise en forme dans les applications compatibles. |
| **Ctrl + Retour arrière** (*Backspace*) | Effacer le mot à gauche du curseur. |
| **Ctrl + ←** / **Ctrl + →** | Se déplacer d’un mot à la fois vers la gauche ou la droite en révisant un texte. |
| **Ctrl + Début** (*Home*) / **Ctrl + Fin** (*End*) | Aller au début ou à la fin d’un document. |
| **Ctrl + ↑** / **Ctrl + ↓** | Se déplacer d’un paragraphe à la fois dans les éditeurs compatibles. |
| **Ctrl + Maj + ←** / **Ctrl + Maj + →** | Étendre la sélection d’un mot. Le même principe s’applique aux flèches ↑ et ↓ dans les éditeurs compatibles. |

Consultez les [raccourcis de Chrome](https://support.google.com/chrome/answer/157179?hl=fr) et les [raccourcis de Windows](https://support.microsoft.com/fr-fr/accessibility/windows/keyboard-shortcuts-in-windows). Microsoft explique aussi comment [copier du texte avec l’Outil Capture d’écran](https://support.microsoft.com/en-gb/windows/apps/use-snipping-tool-to-capture-screenshots). ## Taper sans regarder le clavier

Cette technique s’appelle la **frappe à dix doigts**. Sur un clavier QWERTY, posez les doigts de la main gauche sur **A S D F**, de l’auriculaire à l’index, et ceux de la main droite sur **J K L ;**, de l’index à l’auriculaire. Les petits reliefs sur **F** et **J** permettent de retrouver votre position sans regarder. Utilisez l’un ou l’autre pouce pour la barre d’espacement.

[![Schéma Computer Hope des doigts à utiliser sur un clavier QWERTY](https://www.computerhope.com/issues/pictures/fingers.jpg)](https://www.computerhope.com/issues/pictures/fingers.jpg)

Les touches de ponctuation peuvent varier selon la disposition du clavier.

J’ai appris à taper à dix doigts pendant mon baccalauréat en psychologie à l’Université McGill. Au début, c’était péniblement lent, mais j’ai persévéré. À force de pratiquer, j’arrivais à taper les yeux fermés ou en gardant les yeux sur mes notes ou sur la personne qui donnait le cours, sans regarder mon écran. Je faisais très peu de fautes. À chaque frappe, je voyais la lettre dans ma tête, simplement en sentant où mon doigt avait atterri. Si je me trompais de touche, je m’en rendais généralement compte tout de suite. Je corrigeais la faute avec **Retour arrière** ou **Ctrl + Retour arrière**, puis je continuais.

C’est l’une des compétences les plus utiles que j’ai acquises. Essayez de fermer les yeux le temps de quelques frappes pour sentir quel doigt atteint quelle touche. Tapez ensuite quelques lignes lentement, les yeux sur l’écran, en ramenant vos doigts sur la rangée de référence après chaque frappe. Privilégiez d’abord la précision. [Entraînez-vous avec Typing Study sur un clavier français du Canada](https://www.typingstudy.com/fr-canadian_french-2/lesson/1).
