Commencez par les gestes que vous répétez chaque jour. Le classement tient compte de la fréquence d’utilisation, du nombre de situations où le raccourci fonctionne et du temps qu’il peut faire gagner. Choisissez deux raccourcis du Tier 1 à essayer cette semaine. **Maj** désigne la touche **Shift**.

## Tier 1 · Les incontournables

| Raccourci | Action |
| --- | --- |
| **Ctrl + F** | Trouver un mot ou une expression sur une page Web, dans un PDF ou dans un document. |
| **Alt + D** / **Ctrl + L** | Aller à la barre d’adresse du navigateur. **Alt + D** se fait facilement d’une seule main. Si Google Docs intercepte ce raccourci, essayez **Ctrl + L**. |
| **Ctrl + T** / **Ctrl + W** | Ouvrir un nouvel onglet ou fermer l’onglet actif. |
| **Ctrl + Maj + T** | Rouvrir le dernier onglet fermé. Répétez le raccourci pour retrouver les précédents. |
| **Ctrl + Tab** / **Ctrl + Maj + Tab** | Passer à l’onglet suivant ou précédent dans le navigateur. |
| **Alt + Tab** | Passer d’une application ou d’une fenêtre Windows à l’autre, par exemple entre un article et vos notes. |
| **Ctrl + Retour arrière** (*Backspace*) | Effacer le mot à gauche du curseur. |
| **F2** | Renommer le fichier ou le dossier sélectionné dans l’Explorateur de fichiers Windows. |
| **Win + Maj + S** | Capturer une partie de l’écran. Sélectionnez la zone, puis collez l’image avec **Ctrl + V** ou ouvrez-la dans l’Outil Capture d’écran pour l’annoter. |
| **Win + Maj + T** | Ouvrir l’extracteur de texte intégré à Windows 11, puis sélectionner une zone pour copier le texte d’une image ou d’une page numérisée. Si le raccourci est indisponible dans votre version, faites une capture et choisissez **Actions de texte**. |
| **Win + H** | Dicter du texte. Placez le curseur dans un champ de texte, puis lancez la saisie vocale. |
| **Win + .** | Ouvrir le panneau d’émojis. Tapez un mot pour trouver un émoji. |
| **Win + S** | Ouvrir la recherche Windows pour trouver une application ou un fichier. |

## Tier 2 · Naviguer et réviser plus vite

| Raccourci | Action |
| --- | --- |
| **Ctrl + ←** / **Ctrl + →** | Se déplacer d’un mot à la fois vers la gauche ou la droite en révisant un texte. |
| **Ctrl + Début** (*Home*) / **Ctrl + Fin** (*End*) | Aller au début ou à la fin d’un document. |
| **Ctrl + ↑** / **Ctrl + ↓** | Se déplacer d’un paragraphe à la fois dans les éditeurs compatibles. |
| **Ctrl + Maj + ←** / **Ctrl + Maj + →** | Étendre la sélection d’un mot. Le même principe s’applique aux flèches ↑ et ↓ dans les éditeurs compatibles. |

Consultez les [raccourcis de Chrome](https://support.google.com/chrome/answer/157179?hl=fr) et les [raccourcis de Windows](https://support.microsoft.com/fr-fr/accessibility/windows/keyboard-shortcuts-in-windows). Microsoft explique aussi comment [copier du texte avec l’Outil Capture d’écran](https://support.microsoft.com/en-gb/windows/apps/use-snipping-tool-to-capture-screenshots). [Le raccourci de l’extracteur de texte](https://blogs.windows.com/windows-insider/2025/05/19/announcing-windows-11-insider-preview-build-26120-4151-beta-channel/).

## Nos outils PowerToys favoris

Installez [Microsoft PowerToys](https://learn.microsoft.com/fr-fr/windows/powertoys/install), puis activez les outils qui vous intéressent dans les paramètres de PowerToys. Vous pouvez aussi y vérifier ou modifier les raccourcis.

| Raccourci | Outil | Quand l’utiliser |
| --- | --- | --- |
| **Win + Maj + V** | [Advanced Paste](https://learn.microsoft.com/en-us/windows/powertoys/advanced-paste) | Ouvrir le menu et choisir **Coller en tant que texte brut** pour garder uniquement le texte. Dans la version actuelle, le raccourci direct par défaut est **Ctrl + Win + Alt + V**. |
| **Win + Maj + C** | [Color Picker](https://learn.microsoft.com/fr-fr/windows/powertoys/color-picker) | Prélever une couleur à l’écran et copier son code pour la réutiliser dans une figure ou une diapositive. |
| **Win + Ctrl + T** | [Always On Top](https://learn.microsoft.com/fr-fr/windows/powertoys/always-on-top) | Garder une fenêtre au premier plan, par exemple pour conserver des consignes sous les yeux. Répétez le raccourci pour la libérer. |

## Taper sans regarder le clavier

Cette technique s’appelle la **frappe à dix doigts**. Sur un clavier QWERTY, posez les doigts de la main gauche sur **A S D F**, de l’auriculaire à l’index, et ceux de la main droite sur **J K L ;**, de l’index à l’auriculaire. Les petits reliefs sur **F** et **J** permettent de retrouver votre position sans regarder. Utilisez l’un ou l’autre pouce pour la barre d’espacement.

[Voir le schéma de position des doigts de Computer Hope](https://www.computerhope.com/issues/pictures/fingers.jpg). Les touches de ponctuation peuvent varier selon la disposition du clavier.

Tapez quelques lignes lentement en gardant les yeux sur l’écran. Après avoir atteint une touche avec le doigt correspondant, revenez à la rangée de référence. Privilégiez d’abord la précision. [Entraînez-vous avec Typing Study sur un clavier français du Canada](https://www.typingstudy.com/fr-canadian_french-2/lesson/1).
