A **power user** knows their tools well enough to work more efficiently. That might mean adjusting an app’s settings to fit the way you work, learning a feature that saves several steps, or automating a task you do often.

**Keyboard shortcuts are a good place to start.** When you can switch windows, find a passage in an article, or edit a sentence without reaching for the mouse or opening a menu, it’s easier to stay focused on what you’re doing. Pick two shortcuts from Tier 1 that you can practise in your own work this week.

## Tier 1 · Everyday shortcuts

| Shortcut | What it does |
| --- | --- |
| **Ctrl + F** | Find a word or phrase on a web page, in a PDF, or in a document. |
| **Alt + Tab** | Switch between open Windows apps or windows, for example between an article and your notes. |
| **Ctrl + Tab** / **Ctrl + Shift + Tab** | Go to the next or previous browser tab. |
| **Tab** / **Shift + Tab** | Move to the next or previous link, button, or form field within a window. Press **Enter** to activate a focused link or button. |
| **Ctrl + T** / **Ctrl + W** | Open a new browser tab or close the current one. |
| **Ctrl + Shift + T** | Reopen the most recently closed tab. Repeat to bring back earlier tabs. |
| **F2** | Rename the selected file or folder in Windows File Explorer. |
| **Ctrl + Shift + Esc** | Open Task Manager directly to check what is running or close an unresponsive app. |
| **Alt + D** / **Ctrl + L** | Press **Alt + D** with one hand to jump to the browser’s address bar. If Google Docs intercepts it, try **Ctrl + L**. |

## Tier 2 · Windows tools

| Shortcut | What it does |
| --- | --- |
| **Win + Shift + S** | Capture part of your screen. Drag over the area, then use **Ctrl + V** to paste the image or open it in Snipping Tool to annotate it. |
| **Win + Shift + T** | Open Windows 11’s built-in Text Extractor and select an area to copy text from an image or scanned page. If the shortcut is unavailable on your version, take a snip and choose **Text actions**. |
| **Win + H** | Dictate into a text field. Click where you want the text to go, then start voice typing. |
| **Win + .** | Open the emoji panel. Start typing to find an emoji. |
| **Win + S** | Open Windows Search to find an app or file. |

## Tier 3 · Navigate and edit text

| Shortcut | What it does |
| --- | --- |
| **Ctrl + C** / **Ctrl + V** | Copy the selection, then paste it. |
| **Ctrl + Shift + V** | Paste without formatting in apps that support it. |
| **Ctrl + Backspace** | Delete the word to the left of the cursor. |
| **Ctrl + ←** / **Ctrl + →** | Move left or right one word at a time while editing text. |
| **Ctrl + Home** / **Ctrl + End** | Jump to the beginning or end of a document. |
| **Ctrl + ↑** / **Ctrl + ↓** | Move up or down by paragraph in editors that support it. |
| **Ctrl + Shift + ←** / **Ctrl + Shift + →** / **Ctrl + Shift + ↑** / **Ctrl + Shift + ↓** | Extend the selection by words with **←** or **→**, or by paragraphs with **↑** or **↓** in supported editors. |

See the [Chrome shortcut reference](https://support.google.com/chrome/answer/157179) and the [Windows shortcut reference](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows). Microsoft also explains how to [copy text with Snipping Tool](https://support.microsoft.com/en-gb/windows/apps/use-snipping-tool-to-capture-screenshots). ## Type without looking at the keyboard

This technique is called **touch typing**. On a QWERTY keyboard, rest your left fingers on **A S D F** and your right fingers on **J K L ;**, from the little finger to the index finger on the left and from the index finger to the little finger on the right. Feel for the raised marks on **F** and **J** to find your position without looking. Use either thumb for the space bar.

[![Computer Hope diagram showing which fingers to use on a QWERTY keyboard](https://www.computerhope.com/issues/pictures/fingers.jpg)](https://www.computerhope.com/issues/pictures/fingers.jpg)

Punctuation keys can vary by keyboard layout.

I learned to touch-type during my undergraduate studies in psychology at McGill University. It was painfully slow at first, but I stuck with it. Eventually, I could type with my eyes closed or keep my eyes on my notes or the instructor without glancing back at the screen. I made very few mistakes. With each keystroke, I could picture the letter in my mind just from where my finger landed. If I hit the wrong key, I usually knew right away. I’d press **Backspace** or **Ctrl + Backspace** to fix it and keep going.

It’s one of the most useful skills I’ve developed. Try closing your eyes for a few keystrokes to feel which finger reaches each key. Then practise a few lines slowly with your eyes on the screen, returning your fingers to the home row after each reach. Focus on accuracy first.
