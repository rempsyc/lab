Start with the actions you repeat every day. The tiers reflect how often a shortcut comes up, how widely it works, and how much effort it saves. Pick two from Tier 1 to practise this week.

## Tier 1 · Everyday essentials

| Shortcut | What it does |
| --- | --- |
| **Ctrl + F** | Find a word or phrase on a web page, in a PDF, or in a document. |
| **Ctrl + L** / **Alt + D** | Jump to the browser’s address bar. If Google Docs intercepts **Alt + D**, try **Ctrl + L**. |
| **Ctrl + T** / **Ctrl + W** | Open a new browser tab or close the current one. |
| **Ctrl + Shift + T** | Reopen the most recently closed tab. Repeat to bring back earlier tabs. |
| **Alt + Tab** | Switch between open Windows apps or windows, for example between an article and your notes. |
| **Ctrl + ←** / **Ctrl + →** | Move left or right one word at a time while editing text. |
| **Ctrl + Backspace** | Delete the word to the left of the cursor. |
| **F2** | Rename the selected file or folder in Windows File Explorer. |
| **Win + Shift + S** | Capture part of your screen. Drag over the area, then use **Ctrl + V** to paste the image or open it in Snipping Tool to annotate it. |

## Tier 2 · Navigate and edit faster

| Shortcut | What it does |
| --- | --- |
| **Ctrl + Tab** / **Ctrl + Shift + Tab** | Go to the next or previous browser tab. |
| **Ctrl + Home** / **Ctrl + End** | Jump to the beginning or end of a document. |
| **Ctrl + ↑** / **Ctrl + ↓** | Move up or down by paragraph in editors that support it. |
| **Ctrl + Shift + ←** / **Ctrl + Shift + →** | Extend the selection by a word. The same idea works with ↑ and ↓ in supported editors. |
| **Win + S** | Open Windows Search to find an app or file. |

See the [Chrome shortcut reference](https://support.google.com/chrome/answer/157179) and the [Windows shortcut reference](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows).

## Tier 3 · PowerToys MVPs

Install [Microsoft PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/install) and enable each utility you want to use in PowerToys Settings. You can also check or change the shortcuts there.

| Shortcut | Tool | When to use it |
| --- | --- | --- |
| **Win + Shift + T** | [Text Extractor](https://learn.microsoft.com/en-us/windows/powertoys/text-extractor) | Select text inside a screenshot or scanned page to copy it as editable text. Check the result before using it in a quote or citation. |
| **Win + Shift + V** | [Advanced Paste](https://learn.microsoft.com/en-us/windows/powertoys/advanced-paste) | Open the paste menu and choose **Paste as plain text** to keep only the text. Current PowerToys also offers **Ctrl + Win + Alt + V** as the default direct shortcut for plain text. |
| **Win + Shift + C** | [Color Picker](https://learn.microsoft.com/en-us/windows/powertoys/color-picker) | Sample a colour on screen and copy its code to reuse it in a figure or slide. |
| **Win + Ctrl + T** | [Always On Top](https://learn.microsoft.com/en-us/windows/powertoys/always-on-top) | Pin the active window above others, for example to keep instructions visible while working. Press again to unpin it. |

## Type without looking at the keyboard

This technique is called **touch typing**. On a QWERTY keyboard, rest your left fingers on **A S D F** and your right fingers on **J K L ;**, from the little finger to the index finger on the left and from the index finger to the little finger on the right. Feel for the raised marks on **F** and **J** to find your position without looking. Use either thumb for the space bar.

![QWERTY finger map. Left hand, from little finger to index: QAZ, WSX, EDC, RFV and TGB. Right hand, from index to little finger: YHN and UJM, IK comma, OL period, P semicolon slash. Either thumb presses Space.](../uploads/qwerty-finger-map.png)

The outlined keys mark where your fingers rest. Each colour shows the keys assigned to one finger. The two index fingers each cover two columns. The illustration uses US QWERTY punctuation. Some keys differ on Canadian French and other layouts.

Try a few lines slowly with your eyes on the screen. Reach for each key with its assigned finger, then return to the home row. Focus on accuracy first. [TypingClub’s keyboarding guide](https://typingclub.typingclub.com/m/edclubdocs/media/pdf/typing-jungle-handbook.pdf) illustrates the same finger placement.
